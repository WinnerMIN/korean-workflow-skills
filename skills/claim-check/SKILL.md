# claim-check: 발행 전 주장별 사실 검증

AI로 쓴 홍보문과 블로그 글에는 근거 없는 문장이 섞이기 쉽다. 작성자가 실제로 겪은 사례로는 "신청은 1분이면 됩니다" 같은 단정, 출처를 댈 수 없는 매출 수치, 원문 자료에 없는 숫자가 있었다. 숫자만 원문과 대조하는 검사로는 규정·조건·시행일·효과·비교·단정 같은 주장을 잡지 못한다. 이 스킬은 그런 주장까지 후보로 뽑아 근거를 붙이고 판정하게 한다.

## 준비

- Python 3.9 이상이 필요하다. 외부 패키지는 필요 없다.
- 스크립트 경로는 설치 방식에 따라 다르다. 플러그인으로 설치했다면 `${CLAUDE_PLUGIN_ROOT}/skills/claim-check/scripts/extract_claims.py`이고, 폴더를 직접 복사했다면 `~/.claude/skills/claim-check/scripts/extract_claims.py`이다. 아래 예시는 직접 복사한 경우의 경로다.

## 절차

1. **주장 후보 뽑기**: 바뀐 원고만 넣는다. 빌드된 페이지 전체를 넣으면 메뉴와 표까지 섞여서 후보가 수백 개 나온다.

   ```bash
   python3 ~/.claude/skills/claim-check/scripts/extract_claims.py <원고 파일(.md/.txt/.html)> [-o 출력 폴더]
   # → <원고 이름>.claims/claims.json(원장, 원고 sha256 포함), claims-review.txt(검토표, 마크다운 표)
   # 같은 문장이 여러 곳에 있으면 한 번만 뽑고 also_lines에 줄 번호를 더한다
   # HTML은 본문 외에 meta 설명·JSON-LD(FAQ·행사 정보)·이미지 alt도 읽는다
   # 질문형 문장과 ※ 문장도 수치·단정·규정 표현이 있으면 뽑는다
   ```

   출력 폴더의 기본값은 원고 옆이다. 공개 폴더에 원고가 있다면 `-o`로 내부 작업 폴더를 지정한다.

2. **근거 붙이기(작성자)**: `claims.json`의 주장마다 `evidence`(파일 경로 또는 URL)와 `quote`(근거 원문 인용)를 채운다. 근거를 찾지 못한 문장은 고치거나 지우고 `verdict`를 `삭제함`으로 둔다.
   - 규정 주장(법·세율·요율·신고·요건)은 `korean-law-lookup` 스킬로 1차 출처를 확인한다. 시행일과 적용 조건을 확인했으면 `rule_conditions_checked`를 `true`로 둔다.
   - 광고주나 공식 기관의 표현도 원문을 확인한다. 화면에 보이지 않는 HTML 주석 속 문장은 근거가 아니다.
   - 계산으로 만든 값은 계산식을 `quote`에 적는다.

3. **판정(별도 검토자)**: 원고를 작성하지 않은 읽기 전용 검토 에이전트에게 원고와 `claims.json`을 주고, 주장마다 `근거 있음 / 근거 없음 / 확인 필요`로 판정하게 한다. 검토자는 근거 파일과 URL을 직접 열어 인용이 실제로 있는지, 문장이 인용보다 세게 말하지 않는지(과장·일반화) 확인한다. 스크립트가 놓친 주장(기관명·고유명사·이력처럼 패턴으로 잡기 어려운 것)도 원고에서 찾아 원장에 더한다.

4. **원장 검사**: 판정을 반영한 뒤 아래 명령이 종료 코드 0으로 끝나야 발행하거나 배포한다.

   ```bash
   python3 ~/.claude/skills/claim-check/scripts/extract_claims.py --check <원고 이름>.claims/claims.json <원고 파일>
   # 원고를 다시 읽어 대조한다. 다음 경우에 exit 1:
   #   원고의 주장이 원장에 없음(원고가 바뀐 뒤의 옛 원장 포함), 판정이 '근거 있음'이 아님,
   #   근거·인용이 비었거나 공백뿐임, '삭제함'인데 원고에 남아 있음, 규정 주장의 시행일·조건 확인이 없음
   ```

   `--check`는 판정·근거·인용이 채워졌는지와 원고와의 대응만 기계적으로 확인한다. 근거 내용이 실제로 그 문장을 뒷받침하는지는 3단계 검토자의 판정으로 정한다.

5. 주장이 30개를 넘으면 주장을 나눠 여러 검토자에게 맡길 수 있다. 평소에는 검토자 한 명이 원장 전체를 본다.

## 판정 기준

- **근거 있음**: 근거 원문이 그 문장을 같은 범위와 같은 조건으로 말한다. 날짜·금액·대상이 원문과 일치한다.
- **근거 없음**: 원문에 없거나, 원문보다 넓게 또는 세게 말한다("대부분" → "누구나", "할 수 있다" → "된다").
- **확인 필요**: 원문이 오래되었거나(수정 시각 확인 필요) 원문끼리 내용이 다르다. 내용이 다르면 그 차이를 글에 적는다.
- 단정 표현("무조건", "100%", "1분이면", "보장")은 근거가 있더라도 판매 플랫폼의 금칙어와 광고 표시 기준에 걸리는지 함께 확인한다.

## 하지 않는 것

- 판정을 자동으로 내리지 않는다. 스크립트는 후보를 뽑고 원장의 빈칸을 검사할 뿐이다.
- 원고를 고치지 않는다. 고치는 일은 작성자가 한다.
- 패턴으로 잡기 어려운 것: 기관명이 아닌 고유명사·지역 표현, 문장 밖의 표·도식 속 숫자. 이런 것은 3단계 검토자가 원고를 보고 더한다.
